# v0.1.2 — 仅托盘模式

## 变化

- 自动启动（`--autostart`）后只保留系统托盘图标，不打开主窗口，也不在任务栏显示。
- 主窗口、历史记录、休息确认框都设置为不在任务栏显示；设置页保持原有行为。
- 需要主窗口时：双击托盘图标，或右键托盘 →“打开主窗口”。
- 关闭主窗口只是隐藏回托盘，程序继续计时。
- 其余计时、全屏提醒、锁屏休息、本地记录逻辑不变。

## 使用提示

Windows 11 可能把新托盘图标放进 `^` 溢出区。首次启动后，把
「休养期间工作计时提醒期」拖到任务栏托盘常驻区，之后就能一直看到。

## 验证

- 自动启动参数：`RestWorkTimer.exe --autostart`，启动后主窗口不显示。
- 手动启动：主窗口可显示，但不创建任务栏按钮；托盘图标始终存在。
- 25 个单元测试与 CI 通过。

## 安装

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```
