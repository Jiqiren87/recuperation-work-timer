# 测试计划 — 休养期间工作计时提醒期 v0.1

## 1. 自动化测试

运行：

```powershell
.\.dotnet\dotnet.exe test RestWorkTimer.sln -c Debug
```

当前覆盖（24 个用例）：

| 区域 | 用例 |
|---|---|
| 状态机 | 仅真人输入启动；锁屏清零；睡眠清零但保留 Rest；Rest 中锁屏忽略 |
| 计时 | 29:00 / 29:30 提醒各一次；30:00 进入 Rest；1 分钟周期过滤 60 秒提醒 |
| 休息 | `EnterRestNow`、`ReleaseRest` 新周期、休息时长与结束原因 |
| 配置 | 默认值、保存/读取、非法值钳制 |
| 记录 | work + rest 合并成一行、Rest 未结束显示“进行中”、CSV 导出 |
| 注入过滤 | 键盘 `LLKHF_INJECTED`/`LLKHF_LOWER_IL_INJECTED`、鼠标对应标志 |

GitHub Actions 的 `ci` workflow 在 `windows-latest` 上执行 restore/build/test，并上传测试结果。

## 2. 真机回归

> 需要在实际 Windows 会话中执行。测试锁屏会中断当前桌面，请在方便时操作。

| 场景 | 步骤 | 期望 |
|---|---|---|
| 冷启动 | 退出程序 → 重新运行 | 托盘出现，主窗口显示“待开始” |
| 首次真人输入 | 在 Idle 状态按一次物理键盘/鼠标 | 从完整时长开始，托盘显示倒计时 |
| 60 秒提醒 | 设为 2 分钟，等到 1:00 | 弹窗 + 声音各一次，8 秒后消失 |
| 30 秒提醒 | 等到 0:30 | 弹窗 + 声音各一次 |
| 归零锁屏 | 等到 0:00 | 调用 Windows 锁屏，Rest 状态 |
| 防休眠 | Rest 中运行 `powercfg /requests` | 有本程序的 SYSTEM 请求 |
| 自动化存活 | Rest 中查看后台自动化日志/PID | 进程未结束，后台任务继续 |
| 解锁确认 | 解锁 | 出现休息确认框，15 秒倒计时 |
| 继续休息 | 点“继续休息” | 立即重新锁屏 |
| 解除休息 | 点“结束休息” | 开始新的完整周期 |
| 工作锁屏 | 工作到 10:00 时手动 Win+L → 解锁 | 清零；按键后从完整时长开始 |
| 睡眠恢复 | 工作到 10:00 时睡眠 → 唤醒 → 解锁 → 按键 | 清零；按键后从完整时长开始 |
| 自动输入 | PowerShell `SendInput`/`SendKeys` 循环 | 不启动计时 |
| 真人输入 | 物理键鼠 | 启动计时 |
| 单实例 | 重复启动 exe | 提示已在运行，不出现第二个托盘 |
| 自启 | 设置中开启 → 注销/重启登录 | 自动启动，不弹 UAC |
| 本地记录 | 完成一轮工作+休息 | `sessions.jsonl` 新增 work + rest，历史窗口可见，CSV 可导出 |
| GUI 设置 | 改成 2 分钟、关闭 60 秒提醒 | 下个周期 2 分钟，只在 30 秒提醒 |
| 退出 | Rest 中退出 | 二次确认；退出后防休眠解除，屏幕仍锁定 |

## 4. 测试限制

- CI 无法覆盖真实锁屏、电源状态、硬件键鼠和 Windows 安全桌面。
- 硬件级 KVM/Arduino 模拟输入无法与真人输入区分。
- 屏幕锁定期间无法截图验证弹窗，只能验证窗口/日志；解锁后再做视觉确认。
