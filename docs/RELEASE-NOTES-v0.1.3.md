# v0.1.3 — 最少锁屏休息时间

## 变化

- 新增“最少锁屏休息（分钟）”设置，默认 **5 分钟**，范围 0–180，0 表示不限制。
- 倒计时归零后照常锁屏；如果用户在最少休息时间到达前解锁：
  - 显示“休息未满 · 还需 mm:ss”；
  - “结束休息”按钮禁用；
  - 15 秒不操作自动重新锁屏；
  - 可通过“继续休息”立即重新锁屏。
- 最少休息时间到达后，同一窗口会切换为“可以结束休息”，手动确认后开始新周期。
- 托盘菜单的“结束休息”也受最少休息时间限制，不能绕过。
- 其他行为（全屏提醒、自动锁屏、清零、本地记录）不变。

## 注意

- 最少休息时间是“最早可解除时间”，不是自动解锁时间；到达后仍需手动确认。
- 修改最少休息时间在**下一个工作周期**生效；当前休息周期仍按开始时配置执行。
- 默认 5 分钟；如果你希望恢复旧行为（解锁即可手动结束），把该值设为 0。
